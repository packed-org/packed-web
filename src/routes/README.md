# 📁 routes

Esta pasta gerencia o **roteamento da aplicação** (geralmente utilizando *React Router*).

## 📝 O que colocar aqui:
* **Configuração de rotas:** Mapeamento de caminhos para as telas principais.
* **Guards / Rotas Protegidas:** Componentes de verificação de autenticação ou permissão (ex: redirecionar usuários não logados para o login).
* **Layouts de Rotas:** Estruturas de layout compartilhadas (ex: Layout com barra lateral para Desktop e barra inferior para Mobile).
