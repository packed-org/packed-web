# 📁 assets

Esta pasta armazena os **recursos estáticos** da aplicação que são processados pelo bundler (Vite).

## 📝 O que colocar aqui:
* **Imagens:** PNGs, JPEGs, WebP usados na interface.
* **Ícones e SVGs:** Vetores e ícones customizados.
* **Fontes:** Arquivos de fontes locais (`.woff2`, `.ttf`), caso não utilize fontes via CDN.

> **Nota:** Para ícones do PWA (manifesto) e splash screens do Capacitor, utilize a raiz ou a pasta `public/` conforme a exigência das ferramentas, mantendo aqui apenas os assets consumidos diretamente pelos componentes React.
