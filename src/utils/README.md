# 📁 utils

Esta pasta armazena **funções puras, utilitários e formatadores** que podem ser reutilizados em qualquer parte do projeto.

## 📝 O que colocar aqui:
* **Formatadores:** Máscaras de CPF/CNPJ, formatadores de moeda, data e hora.
* **Validadores:** Funções auxiliares para validação de campos.
* **Helpers genéricos:** Funções de manipulação de arrays/objetos que não possuem estado ou dependência de UI.
